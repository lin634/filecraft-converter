# FileCraft 使用文档

> 版本 v1.2.0 · 作者 gnahihsnil
>
> 一款本地运行的文档处理工具：把 Word / PPT / Excel / PDF 转成 Markdown，调用大模型生成总结、支持基于文档的问答，并提供文件夹式的文件库管理。所有文件解析都在本机完成，只有 AI 总结和问答需要联网。

## 一、快速上手

三步开始使用：

1. 双击 `FileCraft.exe` 启动软件（无需安装 Python 或任何运行库）
2. 把文件**拖进窗口**，或点「导入文件…」选择文档
3. 在「① AI 总结并导出 PDF」里勾选文件，点「生成总结」

接口地址已内置，首次使用前需到「工具 → 设置」填入你自己的 API Key（在 ModelScope 等平台申请）。

运行环境：64 位 Windows 10/11，无需管理员权限。所有文件与配置只保存在本机。

## 二、界面总览

软件分四个标签页，对应四个功能区：

| 标签页 | 作用 |
|---|---|
| ① AI 总结并导出 PDF | 勾选文件生成总结，可编辑、导出 PDF / Markdown / 思维导图 |
| ② 转 Markdown | 把 Word / PPT / Excel / PDF 转成 .md 文件 |
| ③ 文件库 | 文件夹式管理、自动归档、全文搜索、思维导图 |
| ④ 文档问答 | 针对勾选的文件多轮提问 |

四个标签页共用同一份「已导入文件」列表：在任何一页导入（或拖拽）的文件，其它页立刻可见。

## 三、功能详解

### 1. AI 总结并导出 PDF（标签页 ①）

左侧窄栏勾选文件、填写额外要求；右侧宽栏是操作按钮和结果。

- 勾选任意几个文件，点「生成总结」
- 总结按「总体概述 / 各文档要点 / 关键数据 / 风险提示」组织
- 「额外要求」里可以写具体指令，例如：`重点关注财务数据，800 字以内，面向管理层汇报`
- 结果默认显示在「预览」页签；点「编辑 Markdown」可直接修改，切回「预览」自动刷新
- 每次生成自动存入「历史记录」，可随时还原到编辑器（退出软件也不丢）
- 导出方式：「导出为 PDF…」（含中文字体、页码、页眉）、「保存 .md」、「思维导图」

### 2. 文档问答（标签页 ④）

左侧窄栏选择提问范围，右侧宽栏对话，支持**多轮追问**。

- 提问范围有两个来源（左栏页签切换）：
  - **导入的文件**：本次会话导入的文件
  - **文件库**：文件库里的所有文件（含全部子文件夹），勾选即可提问
- 提问示例：`第三季度毛利率是多少？` `和去年比变化的原因是什么？`
- 回答只依据文件内容；文档中没有的信息会明确回答「文档中未提及」，不会编造
- 勾选「要求注明出处」可让回答标注信息来自哪个文档
- 不支持提取文本的文件（如图片）会自动跳过并提示
- 每段对话自动存入「历史记录」，可载入过去的对话继续追问（退出软件也不丢）
- 「清空对话」开始新一轮话题（旧对话仍保留在历史里）

### 3. 转 Markdown（标签页 ②）

支持把以下格式转换为 Markdown 文本文件：

| 格式 | 说明 |
|---|---|
| .docx | 保留标题层级、表格 |
| .pptx | 每页幻灯片文本、演讲者备注 |
| .xlsx | 每个工作表转换为表格 |
| .pdf | 分页文本、表格（仅限文本型 PDF） |

操作步骤：

- 点「导入文件…」或直接拖拽文件、文件夹到窗口
- 在列表中勾选要转换的文件
- 选择输出目录（留空则与源文件同目录），点「开始转换」
- 转换完成后可点「打开选中的 .md」查看结果

### 4. 文件库（标签页 ③）

文件库用可视化文件夹管理你的所有文件，位置默认在 `我的文档\FileCraft`，可整体更换。

**文件夹管理**

- 左侧是文件夹树，支持**多级嵌套**：选中一个文件夹后点「新建文件夹」，就在它下面建子文件夹
- 导入页的「归档到」下拉框可选择文件存到哪个文件夹；文件库里点选文件夹也会同步
- 文件可以选中后「移动到…」其它文件夹（目标有同名同大小文件时自动跳过）
- 文件夹清空后才能删除；删除文件只影响文件库副本，不动原始文件

**自动归档**

- 「导入自动归档」：导入的文件自动复制一份到当前选中的文件夹
- 「总结自动归档」：生成的总结自动存到**来源文件所在文件夹**的「总结」子夹，总结与来源始终对应
- 归档是复制副本、不动原文件；同名同大小的文件不会重复归档
- 两个开关都可以关闭，关掉后可在页面上手动归档

**全文搜索**

- 顶部搜索框同时按**文件名和文件内容**搜索整个文件库
- docx / pptx / xlsx / pdf 会现场解析文本；超大文件（超过 30MB）只搜文件名，PDF 只解析前 50 页
- 结果列出文件名、所在文件夹、命中片段，可直接打开或删除

**思维导图**

- 选中任意 .md 文件，点「生成思维导图」
- 会在旁边生成 `同名.思维导图.html`，浏览器打开即是可缩放、可折叠的思维导图
- 完全离线渲染，发给别人也能直接打开

## 四、设置（工具 → 设置）

首次使用需填入 API Key：选择下方预设（默认 ModelScope 魔搭）或自定义任意 OpenAI 兼容接口，然后填入对应的 Key 即可。

| 服务商 | Base URL | 示例模型 |
|---|---|---|
| ModelScope 魔搭（默认） | https://api-inference.modelscope.cn/v1 | deepseek-ai/DeepSeek-V4.1-Flash |
| OpenAI | https://api.openai.com/v1 | gpt-4o-mini |
| 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4-plus |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| 月之暗面 Kimi | https://api.moonshot.cn/v1 | moonshot-v1-8k |
| 阿里通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| 本地 Ollama | http://localhost:11434/v1 | llama3 |

其它设置项：

- Temperature：越高回答越发散，总结建议 0.3 左右
- 单次输入上限（字符）：超过此值自动分段总结再合并，默认 100000

配置保存在本机 `%USERPROFILE%\.filecraft\config.json`，不会上传。

## 五、常见问题

**双击 exe 提示"已保护你的电脑"？**

未签名程序的正常提示，点「更多信息 → 仍要运行」即可。个别杀毒软件可能误报，添加信任即可。

**AI 功能报"insufficient balance / 余额不足"？**

你的 API Key 对应账户额度用完了，需要到所用平台的充值，或在设置里换成另一个接口与 Key。

**转换结果里没有图片？**

当前版本提取文字与表格，图片暂不导出。

**PDF 转出来是乱的？**

扫描件（图片型）PDF 无法提取文字。判断方法：用阅读器能选中文字的是文本型，不能选中的是扫描件。

**Excel 公式转换后是 0 或空？**

读取的是公式的缓存计算结果，请先在 Excel 中打开保存一次让公式完成计算。

**总结内容太长被截断？**

调大设置里的「单次输入上限」，或减少一次勾选的文件数量。

## 六、已知限制

- 不支持旧版 .doc / .ppt / .xls（请先用 Office 另存为新格式）
- 不支持扫描件 PDF 的文字识别（无 OCR）
- Excel 合并单元格的从属格可能显示为空
- 多栏排版的 PDF 可能丢失原始阅读顺序
- AI 输出质量取决于所配置的模型能力
