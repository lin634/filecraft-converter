# 更新日志

格式：版本（日期）+ 变更要点。新版本写在最上面。
注意：条目标题用 ###（不要用 ##），update_docs.py 会把整份日志同步进使用文档末尾。

### v1.2.0（2026-09-19）

- 新增**历史记录**：「AI 总结」与「文档问答」的全部调用自动存档（本机 history.json），退出重开仍在
- 总结历史可一键**还原到编辑器**；问答历史可**载入对话继续追问**（尽力恢复当时的文件勾选）
- 两个页面均有「历史记录」按钮，支持查看详情与删除；每类保留最近 50 条

### v1.1.0（2026-09-19）

- 新增：文档问答支持直接选择**文件库**里的文件提问——左栏新增「导入的文件 / 文件库」来源切换，文件库列表含全部子文件夹，不支持的格式自动跳过

### v1.0.2（2026-09-19）

- 修复：文档问答页「发送」按钮点击无反应的问题（输入文字后按钮未即时启用，只有回车能发送）；现在输入即亮起，未勾选文件时点击会给出提示

### v1.0.1（2026-09-19）

- 界面调整：「AI 总结」与「文档问答」两页改为左右布局——文件选择在左侧（较窄），预览 / 对话输出在右侧（较宽）
- 「文档问答」恢复为独立标签页（④），与总结页共用导入的文件列表

### v1.0.0（2026-09-19）

- 首个正式版本
- 文档转 Markdown：支持 .docx / .pptx / .xlsx / .pdf
- AI 总结：多文件合并总结、额外要求、长文本自动分段、导出 PDF / Markdown / 思维导图
- 文档问答：基于勾选文件的多轮提问，支持注明出处
- 文件库：多级文件夹、自动归档、文件移动、全文搜索
- 界面：极简白（苹果风）主题
- 内置 ModelScope 兼容接口配置
